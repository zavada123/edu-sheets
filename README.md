# edu-sheets — тренажер «Електронні таблиці»

Навчальний тренажер для уроків інформатики в 6–9 класах. Учень працює в таблиці, схожій на Google Sheets, просто в браузері: вводить дані, пише формули, копіює їх маркером заповнення, форматує клітинки, сортує й фільтрує дані. Тренажер сам перевіряє, чи виконано завдання, і підказує, що не так.

Таблицю малює [Univer](https://github.com/dream-num/univer) (Apache-2.0). Пакет додає до нього завдання, умови перевірки, автоперевірку на сервері, українську мову інтерфейсу й українську нотацію формул.

## Що вміє

- Вигляд і поведінка як у Google Sheets: рядок формул, поле імені, стрічка з вкладками «Основне», «Вставлення», «Формули», «Дані», «Вигляд», аркуші внизу, рядок стану із сумою й середнім.
- Формули з адресами, діапазонами, `$`-посиланнями й функціями (SUM, AVERAGE, MIN, MAX, COUNT, IF, AND, OR, ROUND та сотні інших). Помилки `#DIV/0!`, `#NAME?`, `#VALUE!` як в Excel. `-5^2` дорівнює 25, як в Excel.
- Українська нотація, як у підручниках: `2,5` — число, `=IF(B2>=8000;"так";"ні")` — формула. Після введення тренажер перетворює запис на той, що читає двигун (`2.5`, `,`).
- Маркер заповнення: ряди чисел і копіювання формул зі зсувом адрес.
- Формат: шрифт, жирний, курсив, колір тексту й заливки, межі, вирівнювання, перенесення, об'єднання, числові формати, ширина стовпців.
- Сортування (зростання, спадання, кілька рівнів), фільтр, умовне форматування.
- Інтерфейс українською, назви як в українському Excel: клітинка, аркуш, межі, заливка.
- Працює на комп'ютері, планшеті й телефоні.

## Як описати завдання

Завдання — це об'єкт `Scenario` (`src/scenarios`): що є в таблиці на початку і які умови перевірити наприкінці. Програмувати не треба.

```ts
const fair: Scenario = {
  id: "g6-fair-cookies",
  grade: 6,
  title: "Печиво для ярмарку",
  task: ["У D2:D4 порахуй вартість: ціна × кількість.", "У D5 порахуй загальну вартість."],
  start: [
    {
      // Клітинка — значення, або значення з форматом. Рядок, що починається з =, — формула.
      cells: { A1: { input: "Печиво", style: { bold: true } }, B1: "Ціна", C1: "Кількість", A2: "Вівсяне", B2: 12, C2: 6 },
      widths: { A: 120 }
    }
  ],
  goals: [
    { type: "formula", cells: "D2:D4" },
    { type: "value", cells: "D2:D4", equals: [72, 60, 60] },
    { type: "recalc", cells: "D2", set: { B2: 10 }, equals: 60 }
  ]
}
```

Умови (`Goal`). Значення беруться обчислені: формула рахується за результатом.

| Тип | Що перевіряє |
|---|---|
| `value` | У клітинках такі значення (одне на всі або список по одному) |
| `formula` | У клітинках формули, а не готові числа; формула читає інші клітинки; є потрібні функції (`functions: ["SUM"]`) |
| `recalc` | Формули правильно перераховуються з іншими даними: перевірка підставляє `set` і рахує знову. Так ловиться `=B5*45` замість `=B5*$B$1` |
| `style` | Клітинки мають формат: `bold`, `italic`, `fill`, `color`, `align`, `wrap`, `fontSize`, `format`. `fill: "*"` — будь-який колір |
| `filled` | Клітинки не порожні |
| `sorted` | Рядки діапазону впорядковано за стовпцем і не розірвано (ім'я лишилося зі своїм результатом) |
| `width` | Стовпець не вужчий за `min` пікселів |
| `sheet` | Є аркуш із такою назвою |

Кожна умова має текст для учня й підказку за замовчуванням. Їх можна замінити полями `text` і `hint`. `sheet` вибирає аркуш за назвою.

## Підключення

```bash
npm install github:zavada123/edu-sheets#<коміт>
```

Univer ставиться разом із пакетом як залежність (версії закріплено). Інтерфейс — окремий важкий модуль: близько 1,8 МБ gzip, тому вантажте його ліниво (`React.lazy`).

```tsx
import { EduSheets } from "edu-sheets/react"
import "edu-sheets/style.css"
import { scenarios } from "edu-sheets/core"

<EduSheets
  key={scenario.id}
  scenario={scenario}
  onChange={(workbook) => saveAnswer(workbook)} // уся таблиця після кожної зміни
  onCheck={(solved) => console.log(solved)}
  selfCheck={true} // false ховає «Перевірити», якщо перевіряє сервер
/>
```

Перевірка на сервері (Node, без браузера):

```ts
import { grade, scenarios } from "edu-sheets/core"

const result = await grade(scenario, answer) // answer — те, що прийшло з onChange
// { status: "checked", solved: true, results: [...] } або { status: "invalid" }
```

Сервер рахує всі формули сам тим самим двигуном Univer, тож значенням зі сторінки не довіряє. Відповідь більша за `LIMITS` (10 аркушів, 5000 клітинок) відхиляється.

## Розробка

```bash
npm install
npm run dev        # демо зі всіма завданнями
npm test           # тести ядра й завдань (еталонні розв'язки в src/scenarios/solutions.ts)
npm run build:lib  # збірка пакета в lib/ (lib/ зберігається в репозиторії)
```

Структура:

- `src/core` — модель таблиці, обчислення без сторінки, умови, перевірка, українська нотація. Без React.
- `src/ui` — компонент `EduSheets`, картка завдання, зв'язок з Univer, український переклад (`locale/uk-UA.ts`).
- `src/scenarios` — завдання за підручниками Ривкінда (6 і 8 клас) та їхні еталонні розв'язки.

## Чого ще немає

- Діаграми (6 клас, § 6.4): у відкритому Univer їх немає, плануємо окремо на Chart.js.

- Підказки до функцій англійською, як у Univer.
